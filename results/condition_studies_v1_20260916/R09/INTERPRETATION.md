# R09 실제 결과 해석

20/20 학습 경로·10,240 본업데이트와 smoke10을 완료했다. 176개 주지표 scalar 및66개 평균/합계/패턴 scalar 검산, 60개 선택용 점수와15개 모델 선택, 20개 최종 resume·원점 순서 검사를 통과했다. 선택용 seed와 두 반복 seed를 분리했고, 다섯 군 모두 V에서 학습률1e-4를 선택했다. 반복 선택은 I0/I3/I4 두 seed 모두256회, I2 두 seed 모두512회, I1은73101에서512회·73102에서256회다.

## 전체 시간별 오차와 추가 가치

선택된 반복 평균 NRMSE는 FROZEN0.715941, FINE_ONLY I0 0.551349, MIXED I1 **0.538191**, IMPUTE I2 0.686144, UNIFORM I3 0.607733, NULL I4 **0.606694**다.

NULL 대 MIXED의 gain은 **−12.728% [−18.604%,−8.311%]**이고 두 seed 모두 악화했다. NULL 대 UNIFORM은 +0.171% [−0.159%,0.566%]로 불확실하며 seed73101은−0.214%,73102는+0.577%로 방향도 다르다. NULL 대 IMPUTE는+11.579% [8.667%,14.897%]지만, IMPUTE가 수학적으로 NULL 계수1인 목적과 같으므로 이는 보존 강도1 대0.1의 비교다. 새로운 보존 원리가 생겼다는 증거가 아니다.

고정512 결과에서도 NULL 대 MIXED는−16.465%, 대 UNIFORM은−0.594%(구간은0포함)다. 선택 기준을 고정512로 바꾸거나 좋은 seed만 취하지 않았다.

일반 MIXED는 FINE_ONLY보다2.387%, FROZEN보다24.828% 낮은 평균 오차를 보였다. 이는 부가적인 점추정 설명이며 사전 NULL 핵심 대비를 대체하거나 새 독립 확증으로 쓰지 않는다. 집계 정보로 얻을 수 있는 유용한 수준 변화가 있으나 새 보존 규제 없이 MIXED가 더 낮은 전체 오차를 얻었다.

## 평균·합계·세부 패턴의 손익

아래 표는 모든 반복 seed의 평균이며 각 seed 원점수는 secondary_scores.csv에 있다. 합계 RMSE는 원자료 단위를 유지하고 다른 두 지표는 TRAIN sigma로 정규화했다. 서로 다른 지표를 합산하지 않는다.

| 군 | 하루 평균 NRMSE | 하루 합계 raw RMSE | 평균 제거 패턴 NRMSE |
| --- | ---: | ---: | ---: |
| FROZEN | 0.217504 | 210.522695 | 0.676355 |
| FINE_ONLY | 0.280834 | 251.821580 | 0.465484 |
| MIXED | 0.241129 | 223.515844 | 0.475581 |
| IMPUTE | 0.249245 | 222.244688 | 0.625576 |
| UNIFORM | 0.221729 | 204.568344 | 0.558888 |
| NULL | 0.222531 | 204.657485 | 0.557236 |

NULL은 MIXED보다 평균/합계 오차가 작지만 패턴 오차가 크고, 주목적인 실제 시간별 오차도 크다. 평균을 잘 맞춘 사실로 주목적을 바꾸지 않는다. FROZEN 자체의 패턴 오차가 커서 그것에 대한 보존이 유용한 적응을 제한했을 가능성과 양립하지만, 이 비교만으로 일반적인 실패 원인을 확정하지 않는다.

입력14일 중 상세 관측이 있는 날 수1~6의 모든 상태를 context_state_scores.csv에 공개했다. NULL은 이 여섯 상태 각각의 반복 평균에서도 MIXED보다 시간별 오차가 컸다. MIXED 대 FINE_ONLY도 모든 상태에서 좋아진 것은 아니며, 상세 context1~3일 상태에서는 MIXED가 더 나빴다. 유리한 상태만 제외·채택하지 않았다.

## 정보 권한·gradient·자원

I0는 상세 정답16원점을32회씩, I1~I4는 상세16+집계48의64원점을8회씩 사용했다. 업데이트는 같지만 고유 감독 정보량은 다르다. 모든 군이 같은 허용 context와 해상도 mask를 받았으므로 I0가 집계 context도 전혀 못 받는 대조는 아니다. V_SELECT의 상세 정답32일은 명세가 허용한 선택 정보다. 상세 검증 정답도 없는 환경을 해결했다고 주장하지 않는다.

절대시간24h block 권한에 따라 숨긴 세부값을 packet에서 제거하고, 미래 평가 집계량은 입력에 넣지 않았다. 첫 R09 학습 전에 TRAIN 경계를 넘는 미완료 하루를 통계에서 제외한 교정을 기록했다. 원래 통계를 보존했고 V/E poison 불변 및 독립 scalar 통계 검산을 통과했다. 원점·정답·학습률을 결과에 맞춰 바꾸지 않았다.

전체 학습의 gradient clipping은 I0 약71.97%, I1~I4 약32.81~34.81%였다. 높은 clipping 비율을 숨기지 않으며 고정 clip=1을 재조정하지 않았다. 사전에 정한 첫 aggregate TRAIN 네 원점×두 seed의 선택 가중치에서 가중 규제/task gradient norm 비율은 UNIFORM 평균0.4394(범위0.1990~0.7326), NULL 평균0.1727(0.0487~0.3199)이었다. 같은 계수0.1이 같은 gradient 총량을 뜻하지 않음을 직접 확인했다. 이는 선택 가중치의 제한된 진단이며 모든 역사적 update의 분해가 아니다. 검사 중 optimizer0회·가중치 변경0이다.

다섯 군 모두 LoRA1,179,648개와 같은 입력5행·C336/H24를 사용하고 별도 보조 학습계수는 없다. 경로당 optimizer49.67~49.87초, 선택 포함62.59~62.89초, peak allocated 약618MiB다. 외부 compute 오염은0updates다. CPU 보고 작업을 병행했으므로 작은 시간 차이는 격리된 속도 우위로 해석하지 않는다.

## 이번 범위의 판단

실행과 검산은 완료했다. 기본 학습의 예측 개선은 관측됐지만 NULL의 추가 가치는 MIXED에 비해 부정적이고 UNIFORM에 비해 불확실했다. 평가 원점은64개 다른 날짜·32개 관측 주간 블록이지만 재사용된 개발 기간이며 새 독립 시험이 아니다. 시간 집계·상세 복원·nullspace 투영은 알려진 원리이고 정식 Denton/Chow–Lin 계열과 동등 예산 비교를 하지 않았다. 새 PEFT 방법으로 집중할 근거를 확보하지 못했으며 추가 학습은 실행하지 않는다.
