# 결과 보고와 실행 조건의 분리

REPORT/STATUS의 EVIDENCE는 완료된 사전 대비를 해석하는 문서 태그다. 후속 후보를 허용하거나 막는 실행 gate로 사용하지 않는다. 실행 순서·학습률·seed·원점·목표·허용오차는 최초 명세와 감사된 학습 전 구현 수정 그대로다.

- 핵심 직접 대비의 CI가 모두 양수인 경우 제한된 범위의 유망한 근거로 표시하되, 다른 조건/seed 반전·단순 대안·신규성은 별도로 설명한다.
- 핵심 추가 구성요소가 가까운 대조보다 악화하고 해당 CI가 음수이면 제한된 범위의 부정적 근거다. 실행 실패가 아니다.
- POSITIVE_UNCERTAIN 태그는 양의 점추정이나 성공을 보장하지 않는다. 음의 점추정이지만 구간이0을 포함하는 경우도 해당할 수 있다. 실제 부호와 원점수를 반드시 같이 읽는다.
- N06처럼 단순 AR1의 주목적 개선이 확인되고 복잡한 두 대안이 AR1을 넘지 못하면 SIMPLE_METHOD_SUFFICIENT로 보고한다. 이는 알려진 단순 처리의 충분성이고 새 PEFT 방법의 성공이 아니다. 다른 목표(Brier 등)의 손해를 함께 보고한다.
- INIT 선택은 실제 학습 경로를 모두 계산한 뒤의 선택 결과다. 미실행과 다르고, INIT가 둘 다 선택된 제안군은 NO_SELECTED_ADAPTATION으로 구분한다.

이 태그만으로 전체 우승·논문 PASS·후속 주제를 자동 결정하지 않는다. 최종 shortlist는 한국어 FINAL_DECISION의 문제별 근거와 한계로 최대2개/0개를 정한다. 이 문서는 수치 기준을 바꾸는 새 계약이 아니다.

R04는 정확도 track의 CI 태그를 그대로 적용하지 않는다. 계약대로 정확도1% 보호 여부와 수정량 직접 대비를 함께 읽으며, 정밀도 자체의 추가 향상을 별도 성공 조건으로 요구하지 않는다. 이 보고 분기는 R04 E 채점 이전에 정리했다. 수치·선택·규제 강도는 변경하지 않았다.
