# 무엇이 좋아졌고, 무엇이 아직 부족한가

이번 결과는 “학습 자체가 모두 실패한다”는 결과가 아니다. 8개 학습과 평가를 정상 완료했고, 저장 예측 200개의 원점수와 선택 체크포인트 8개의 재생을 검산했다. 동결 가중치와 버퍼는 그대로였고 의도한 side 구성요소와 head는 실제로 업데이트됐다. 새로운 변경의 예측 가치와 신규성이 충분한지는 별도로 판단해야 한다.

## 구성요소의 추가 가치

| 비교 | 이번에 확인한 것 | 아직 말할 수 없는 것 |
|---|---|---|
| PRIOR 대 SIDE | 같은 용량·구조에서 attention 기준분포를 추가했을 때 선택 모델의 평균 MSE가 전력 1.007%, 교통 1.423% 개선 | 두 seed에 일관된 효과, 모든 학습 예산에서의 우위 |
| PRIOR 대 동일용량 마지막 pointwise adapter | 전력 3.656%, 교통 1.607% 평균 개선. 두 원천 모두 두 seed가 개선 방향 | attention만의 인과효과. 층별 연결·비선형 구조·정규화도 함께 다름 |
| PRIOR 대 head-only | 전력 5.950%, 교통 8.275% 평균 개선 | 새 prior만의 가치. side 경로와 추가 학습 파라미터가 함께 추가됨 |
| PRIOR 대 균형 표본 LoRA+head | 전력 평균은 0.166% 개선, 교통은 3.668% 악화. 학습 peak allocated 약 60% 절감 | 표준 LoRA의 예측 정확도를 일반적으로 유지하거나 능가한다는 주장 |

수치는 모두 먼저 두 seed의 MSE를 평균한 뒤 비교한 값이다. 특히 PRIOR의 SIDE 대비 이득은 seed 41000에서 전력 −1.424%·교통 −0.407%, seed 41001에서 전력 +3.377%·교통 +3.190%였다. 평균을 보고 양쪽 seed에 효과가 있었다고 쓰면 안 된다.

고정한 같은 epoch/updates 비교에서는 PRIOR 대 SIDE가 전력 +0.845%, 교통 −2.252%였다. 교통의 선택 모델에서는 양성이지만 짧은 고정 학습량에서는 음성이다. 따라서 현재 관찰은 “같은 학습량으로 더 빨리 좋아진다”는 증거가 아니다. 특히 seed 41001의 선택 checkpoint는 PRIOR가 SIDE보다 더 많은 updates를 사용했다. 같은 선택 기회를 주었다는 것과 실제 선택 비용이 같다는 것은 다르다.

## 실패 원인으로 확정할 수 있는 범위

[확인] 이번 구현에서 prior는 사용됐고 업데이트도 발생했다. 기존 학습 입력 8개를 사용한 CPU 관찰에서 층별 prior는 균일분포와 분명히 달랐다. “새 항이 항상 중립이어서 아무 일도 안 했다”는 설명은 이 관찰과 맞지 않는다. 다만 CPU FP32 관찰을 GPU BF16 전체 입력의 분포로 일반화하지 않는다.

[확인] 저장 LoRA에서 Q/K와 V를 각각 제거했을 때 모두 악화한 이전 진단은 공동으로 적응한 경로에 대한 의존성을 보여준다. 이 의존성이 동결 backbone 옆의 작은 경로만으로 회복된다는 보장은 없다. 현재 side 모델들은 backbone의 다음 층에 적응 결과를 되돌려 주지 않는다. 이 구조 차이는 구현상 사실이다.

[추정] 여러 head의 확률을 평균하면서 역할별 정보를 잃었거나, side 표현과 동결 attention 사이의 맞지 않는 부분이 남았을 수 있다. 또는 표현 능력·최적화·checkpoint 선택의 차이가 중요할 수 있다. 이번 비교는 이 원인들을 분리하지 않았으므로 어느 하나를 실패 원인으로 확정하지 않는다. 같은 파라미터 수가 같은 표현 능력과 최적화 난이도를 뜻하지 않는다.

## 이전 시도와 연결해 판단하면

과거 시작 위상이 한쪽으로 치우친 학습 표본을 균형화한 것만으로 표준 LoRA가 크게 개선됐다. 이어 head-only보다 LoRA가 전력 5.794%·교통 11.520% 추가 개선한 결과도 있었다. 이는 현재 MOMENT 설정에서 적응 자체가 불가능하다는 주장에 반대되는 근거다. 알려진 표본 구성과 표준 PEFT의 유용성이지 새 방법론의 성공은 아니다.

같은 용량의 마지막 adapter, 같은 시간대 입력 조건화, 이번 층별 side 경로는 서로 다른 제한을 확인했다. 단순히 이름이 다른 모듈을 붙이면 강한 LoRA를 넘을 것이라는 기대는 근거가 부족하다. 이번 후보는 작은 평균 추가 가치와 메모리 절감을 보여 줬지만, seed 일관성·강한 기준선 대비 예측 가치·선행 대비 차별성이라는 서로 다른 문제가 남았다.

이 결과를 Chronos의 건물 cold-start 실패나 Query 수치 중단의 공통 원인으로 확대하지 않는다. 데이터·모델·학습 규칙이 다른 작업이다.

## 논문 주제로 남은 빈칸

저메모리 side tuning 자체는 LST/LAST에 이미 있다. softmax(log P0 + S) 역시 기준분포를 곱해 정규화하는 알려진 형태다. 현재 결합에 평균 이득이 있어도 그것만으로 새로운 PEFT 방법론을 확보한 것은 아니다. [학습 전 선행 검토](RESEARCH_REVIEW.md)에 직접 읽은 범위와 미확인 부분을 남겼다.

이 실행의 결과에 맞춰 “전력에서만”, “좋은 seed에서만”, “정확도 대신 메모리만”으로 목적을 바꾸지 않는다. 이번 판정은 후보 보류이며, 주제를 확보했다는 결론은 내리지 않는다. 새 방법론으로 투자하려면 현재 반복 노출된 E 밖의 고정 평가와 가까운 선행을 넘는 구체적 차이가 필요하다. 이번 자동 실행에서는 추가 학습을 시작하지 않았다.
