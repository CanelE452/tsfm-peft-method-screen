# Persistence-masked residual adaptation: 후속 검증 질문

잘 적응된 B0와 원래 입력을 유지하면서 추가 어댑터의 수정 위치를 관측 지속성으로 제한하는 현재 C3를 검증한다. Electricity SHIFT8의 기존 양성 결과를 보고 좁힌 가설이며, 과거부터 확증 가설이었다고 주장하지 않는다. 새 구조 또는 gate 탐색은 없다.

주 질문은 B0가 학습하지 않은 전력 계열의 SHIFT8에서 C3가 C0와 C2보다 나은지다. 계열의 이전 성능 노출을 배제할 근거가 부족하므로 독립 자료 확인은 UNRESOLVED이고, 고정된 hash 순 16계열의 탐색적 전이를 실행한다. 같은 날짜·전력 환경의 상관도 남는다.

MEAN·ROTATE16·RECENCY는 새로운 방법 후보가 아니라 보정량·위치·최근성 설명을 반박하는 대조다. 기존 C3를 튜닝하지 않는다. C2_SHRINK와 C0_BIAS는 원래 네 계열 V에서만 정한 출력 대조다.

새 seed, ETTm2의 별도 B0 학습 및 추가 적응, 크기·길이·patch 경계·ramp/pulse 검사를 정해진 예산에서 수행한다. 기존 E와 ETTm2의 과거 노출을 공개한다. 실제 오류·변화 레이블과 공식 COSA/TATO·다른 backbone 비교는 이번에 수행하지 않는다. 결과는 기전·전이·손해·비용·신규성으로 나누며 논문 PASS를 선언하지 않는다.
