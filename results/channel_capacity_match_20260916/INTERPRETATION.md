# 동일 용량 비교로 좁힌 원인과 다음 연구 질문

[확인] 4/4 fits와 평가가 정상 완료됐다. 이번 결과는 **용량 확대만으로 LoRA의 이득을 회복하지 못했다**는 개발 근거다. 새 방법론 주제는 아직 확보하지 못했다.

## 결과가 구분해 준 설명

| 설명 | 관찰 | 이번 판단 |
|---|---|---|
| 마지막 adapter가 작아서만 실패했다 | 폭16→168에서 교통 MSE 3.201% 개선, 전력 0.031% 악화 | 용량은 일부 관련되지만 이것만으로 두 원천의 차이를 설명하지 못함 |
| 마지막 adapter만으로 LoRA를 대체할 수 있다 | 같은761,952 trainables에서 LoRA보다 전력3.623%·교통5.361% 악화 | 이번 단일 설정에서는 지지되지 않음 |
| PEFT 자체가 학습되지 않는다 | 큰 adapter는 head-only보다 전력2.381%·교통6.777% 개선; LoRA는 이보다 더 좋음 | 현재 MOMENT 경로에는 유용한 적응 신호가 있음 |
| 같은 시간대의 입력 유사도를 추가하면 해결된다 | 직전12-fit의 CONDITIONED는 같은용량 POINTWISE 대비 추가 이득 없음 | 그 후보를 다시 성공으로 분류하지 않음 |

[확인] 같은 updates에서도 큰 adapter는 LoRA보다 전력4.182%·교통3.378% 나빴다. 각방법의 V 선택 epoch 차이만으로 현재 격차가 사라지지는 않는다. 폭 확대는 같은 updates의 작은 adapter 대비 두 원천 평균을 개선했지만, 최종 V 선택 비교의 전력 이득은 유지되지 않았다. [원점수](macro_comparisons.csv).

[한계] 전력 seed41001은 공통 patience5 정책에 따라13epochs에서 종료됐다. 최대5080 중448updates를 쓰지 않은 이유이며 중단 오류가 아니다. 나머지3fits는20epochs 상한에 도달했다. 학습률·초기화 기하·수렴 정도가 완전히 통제된 인과 실험은 아니다. 따라서 'encoder 내부 변경만이 유일한 해답'이라고 확정하지 않는다.

## 자원 이득은 별도 결과

[확인] head 포함 학습 파라미터는 LoRA와 같고, 학습 peak allocated memory는 약73% 작았다. 이 수치는 전체 GPU 사용량이나 peak reserved memory와 다르다. frozen encoder의 역전파를 생략한 실행 경로에서 얻은 측정이다. 예측 악화가 함께 있으므로 기존 정확도 기준을 자원 기준으로 바꾸어 PASS라고 하지 않는다. 총 모델 파라미터는 기존 모델에 adapter를 추가하므로 줄지 않는다. [자원 원점수](comparisons.csv), [정책 재검산](completion_audit.json).

## 지금 추천하는 연구 질문과 아직 없는 것

[제안] **시간 패치 사이의 관계를 적응시키면서, 표준 LoRA의 예측 이득을 더 적은 학습 메모리로 유지할 수 있는가?** 우선 범위는 현재의 MOMENT-small·전력/교통·96→96이다. 이는 방법론을 개발할 연구 질문이며, 검증된 새 알고리즘 이름이나 성능 약속이 아니다.

[추정] 마지막 위치의 pointwise 변화와 encoder 내부 q/k/v 변화의 차이가 남아 있다. 패치 간 관계 수정은 그 차이를 설명할 후보 원인이다. 하지만 frozen encoder의 표현에도 이미 시간 정보가 있으며, 마지막 adapter가 시간 정보를 전혀 쓰지 않는다고 하면 틀리다. 용량·최적화·삽입 위치·시간 혼합 중 어느 것이 지배적인지는 아직 분리되지 않았다.

[다음 우선순위] 이미 저장된 LoRA 체크포인트와 train/V 입력에서, LoRA가 바꾼 표현과 시간 관계를 먼저 측정한다. 그 증거로 가장 가까운 단순한 학습형 시간 혼합 대조와 구체적 차이 하나를 명세할 수 있을 때만 후보 설계가 가능하다. 일반 attention, 저랭크 분해, 일부 layer만 학습하는 규칙을 그대로 쓰면 알려진 대조로 기록한다. 이4-fit 실행에는 이 추가 진단·후보 학습을 포함하지 않았다.

[한계] 현재 E는 반복 노출된 DISCOVERY다. 새 메커니즘을 이 자료에서 고르고 같은 자료의 양성만으로 독립 PASS를 줄 수 없다. 미노출 평가, 추가 backbone, 직접 선행 대비 신규성은 모두 남아 있다. 또한 여기서 확인한 sampling/adapter 결과를 Chronos 건물 cold-start나 Query 수치 중단의 원인으로 일반화하지 않는다.

## 가까운 선행을 확인한 범위

[확인] [ST-LoRA, arXiv v2(2025), §3](https://arxiv.org/html/2404.07919v2)는 노드별 저랭크 변화, residual predictor의 적층, 입력·출력을 활용한 gated 결합을 설명한다. 따라서 '채널별 저랭크 출력 보정'만으로 새 주제라고 하기 어렵다. 공개 논문의 수식을 읽었으며 이번 코드와의 동치 여부나 논문의 모든 실험을 재현하지 않았다.

[확인] [TRACE, arXiv v1(2025), §4](https://arxiv.org/html/2503.16991v1)는 MOMENT의 예측 head 축소와 중요도 기반 LoRA 선택을 다룬다. 단순 head 압축 또는 학습 위치 선택 자체만으로 차별성을 주장할 수 없다. 이 선행은 이번 메모리 수치나 새 가설의 성능을 보장하지 않는다.

[구분] 이 문서는 결과 이후 해석이다. 봉인된 PROTOCOL/RESEARCH_REVIEW·학습 코드·기준은 수정하지 않았다. 새 수식의 DISTINCT_HYPOTHESIS 판정은 아직 부여하지 않았다.
