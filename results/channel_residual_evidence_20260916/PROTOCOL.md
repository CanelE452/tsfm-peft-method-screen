# 단순 LoRA의 남은 잔차 — 분석과 알려진 통계 대조

2026-09-16, 기준45f2631. 신규 신경망 학습0, GPU 작업0. 기존 두 원천·두 seed의 LH 선택 checkpoint 예측만 사용한다. 새 후보·새 데이터·새 split을 추가하지 않는다. 성능을 보기 전에 아래 분석·대조를 고정한다.

질문: 남은 오차에 채널별 평균/24시간 반복 성분이 얼마나 있으며, 이미 관측된 오차만으로 그 일부를 예측할 수 있는가?

1. 직교 분해: 각96시간 잔차 e를 전체 평균 b, 네 일의 같은 시간 평균에서 b를 뺀24시간 반복 s, 나머지 r로 분해한다. mean(e²)=b²+mean(s²)+mean(r²)를 검산한다. 미래 정답으로 계산한 에너지 분해는 진단이며 실행 가능한 회복량이 아니다.
2. 고정 통계 대조4개: UNCHANGED, EXPANDING_BIAS(관측 완료한 이전 forecast 잔차의 채널별 전체 평균), EXPANDING_DAILY(이전 잔차를 절대 row index mod24에 맞춘 채널별 평균), LAST_BIAS(가장 최근 관측 완료 forecast의 채널별 평균). 모두 p−추정잔차, 계수1. grid·shrink·최선 방법 선택 없음. 데이터 시작 row의 실제 시각을 알고 있다고 주장하지 않는다.
3. 시점o에서 origin+96<=o인 과거 forecast만 통계에 반영한다. V 마지막 이후 E까지 시간 gap도 검사한다. 최초 잔차 없으면 보정0. V 상태를 이어 E를 계산한다. 현재/미래 정답을 오염시켜도 현재까지의 보정 예측이 바뀌지 않는지 검사한다.
4. V는 전체 V로 이미 선택된 고정 LH checkpoint의 사후 진단이다. V의 전체 pipeline을 순수 online 성능으로 주장하지 않는다. E 적용은 V checkpoint 고정과 관측된 과거 residual만 사용하지만, E 자체가 과거 연구에 노출되어 있으므로 독립 평가가 아니다.
5. 원점수: normalized 채널 macro MSE/MAE, 원 단위 MAE, 같은 집단 macro에서 개선율. 모든4방법×2원천×2seed×V/E를 보고한다. 회귀 optimizer fit0; 평균 통계 업데이트의 처리 forecast 수/상태 scalar 수를 별도로 기록한다.
6. 분해 vector/scalar 일치, 원본 hash/정답/시점 비교, 상태의 인과성, 특수 반례에서 24시간 phase 정렬, 모든 과거 파일 불변을 검사한다. 새 PASS 기준은 만들지 않는다. 알려진 대조의 유용성은 신규성이나 neural PEFT 성공이 아니다.

가능한 판단: 보정이 좋아지면 새 후보는 이 단순 대조까지 넘어야 한다. 보정이 좋지 않으면 '잔차가 크다'만으로 잔차 학습 후보를 정당화하지 않는다. 단순 오차 모델링·주파수별 adapter에는 가까운 선행이 있으므로 구체적 차별점 검토를 이어간다. 이 작업 뒤 추가 학습을 자동 실행하지 않는다.
