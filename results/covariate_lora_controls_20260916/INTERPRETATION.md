# 무엇이 좋아졌고, 왜 아직 새 PEFT 방법의 PASS는 아닌가

[확인] 이번에는 **이전 예보 버전을 교대로 사용하는 LoRA 학습**에서 양성 신호를 얻었다. 최신 예보 조건의 주지표는 무학습 INIT0 0.149478673 → VINTAGE 0.142617770, 상대 4.590% 개선이다. 두 seed 모두 개선(5.108%, 4.071%)했고, V에서 두 seed 모두 120updates를 선택했다. STD/EXODROP은 둘 다 ZERO를 선택했다. 학습 실패나 임계값 변경으로 만든 결과가 아니다.

다만 4개월 중 2개월만 두 seed 평균이 개선하고 월 block bootstrap95%는 [-1.066%, 10.775%]다. 한 타깃의 이미 노출된 D를 반복 사용한 개발 신호다. 독립 평가 PASS, 일반적 강건성, 새 PEFT 방법의 신규성으로 확장할 수 없다.

## 반복된 부진을 해석할 때 이번에 더 알게 된 점

[확인] STD의 첫 epoch 평균 native 학습손실은 두 seed 약0.503이고 마지막 epoch에는0.247/0.241로 내려갔다. 그런데 V에서는 0.131568에서0.135012/0.136770으로 나빠졌다. 따라서 이번 STD의 부진은 optimizer가 작동하지 않은 문제가 아니다. 동결 가중치 보존과 intended LoRA 업데이트도 검사했다.

[확인] 고정120에서 STD의 최신 입력 80% 구간 포함률은 두 seed 평균69.401%, 초기79.948%에서 낮아졌다. 구간 폭도 초기256936.74에서191199.00로 줄었다. VINTAGE는 포함률76.953%, 폭237322.33이다. 동시에 VINTAGE의 median RMSE는134226.01로 초기140815.23 및 STD139530.81보다 작았다. **이번 변화는 구간 폭만의 변화도, point 예측만의 변화도 아니다.** raw 단위의 값이며 서로 다른 타깃 사이 규모 비교가 아니다.

[추정] 적은 최신 예보 패턴을 반복 학습하면 학습 자료에는 잘 맞아도 다른 시기의 예보 오차와 부하 관계에 과하게 맞출 수 있다. 실제 이전 예보를 노출하는 학습은 이런 문제를 일부 줄일 가능성이 있다. 그러나 이번 비교만으로 원인을 확정하지 않는다. regularization, 추가 입력 정보, 난이도, 예보 나이의 순환이 모두 경쟁 설명이다. 각 군의 학습 입력이 다르므로 군 사이 training loss 크기를 같은 모집단 성능처럼 비교하지 않는다. EXODROP의 0 채널은 물리적으로 삭제되지 않고 target1+covariate3행을 유지한다. native instance normalization도 유지하므로 surviving 채널의 inverted scale 효과는 원 논문 backbone과 같다고 보장할 수 없다. 이번 비교는 Chronos 경로에서 같은 masking 규칙을 적용한 대조다.

과거 모든 실패가 이 원인이라는 주장도 하지 않는다. MOMENT 채널 실험, Query 수치 실패, 건물 cold-start는 모델·목적·데이터가 달랐다. 이전의 실행 실패와 추가 가치 미확보 판정을 보존한다.

## 지금 좁힐 수 있는 연구 질문

[설계/미실행] 연구 축을 유지한다면 질문은 **“날씨 예보가 갱신되는 조건에서, 유용한 공변량 신호를 유지하면서 LoRA 적응 손해를 줄일 수 있는가?”**로 좁힌다. 이번 결과는 이 질문의 단순 대조를 확보한 것이며 제안 방법을 확보한 것은 아니다.

다음 방법이 의미를 가지려면 일반 LoRA뿐 아니라 **이번 VINTAGE와 EXODROP**에 대한 추가 가치가 필요하다. 기존 예보를 섞는 정책에 새 이름을 붙이거나, 알려진 정규화·gate를 붙였다는 이유만으로 신규성을 주장하지 않는다. 오래된 예보의 부진을 보고 최신 입력만 남겨 보편적 강건성 성공이라고 바꾸지 않는다.

단순 신뢰도 gate는 앞선 [사후 진단](../../research/covariate_reliability_diagnostic_20260916/REPORT.md)에서 이미 직접 근거가 약했다. 현재 양성 신호가 그 gate를 소급 정당화하지 않는다. [Exogenous Dropout §3.5](https://arxiv.org/html/2607.05452v1#S3.SS5)의 채널 masking은 알려진 기준이며, [CoRA](https://arxiv.org/html/2510.12681v1#S3) 같은 공변량 적응과도 신규성을 구분해야 한다. 두 논문의 전체 성능 재현은 하지 않았다.

**이번 결정: 알려진 예보 버전 학습의 양성 신호는 유지, 새 PEFT 방법론 PASS는 보류.** 새로운 수식의 필요성과 가까운 선행 대비 차이를 정당화하지 못한 상태에서 추가 후보 학습을 자동 실행하지 않았다. 독립 원천·타깃의 사전 고정 검증도 아직 없다.
