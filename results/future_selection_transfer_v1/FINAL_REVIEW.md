# 미래 구간 비교 최종 검토와 요청 작업 현황

승인받은 후속 비교를 완료했다. 실제 실행은 168.90초(약 2분 49초), forward 1,064회, 새 학습/역전파/optimizer update 0회다. 93개 테스트와 556개 독립 수치 검산이 통과했다. 기존 파일 1,257개를 변경하지 않았으며 GPU 작업은 종료되었다.

RECENT4 대비 SPREAD4의 source-balanced 차이는 +0.1517 percentage points(%F0 개선율 차이)다. 원천별로 Beijing +0.5747pp, Electricity +0.1145pp, ETTm2 −0.2341pp였다. 동일 예측을 선택한 셀은 1/12이고 11/12에서 다른 선택이었다. 단순히 후보가 같아 차이를 볼 수 없었던 실험은 아니다.

전체 평균의 F0 대비 개선율은 FIXED +0.6582%, RECENT4 +0.6121%, SPREAD4 +0.7638%, ALL16 +0.6850%다. SPREAD4는 전력의 모든 셀에서 F0를 선택해 RECENT4의 평균 악화를 피했지만, FIXED는 같은 원천에서 +0.2893%였다. 따라서 SPREAD4가 모든 유효한 개선을 찾아낸 것도 아니다. 사전에 고정한 FIXED와 ALL16 참조도 함께 읽어야 한다.

판독은 **제한적인 선택 전달 신호와 원천별 반례가 공존**한다는 것이다. 이 결과로 검증 시간 배치가 전체 PEFT 실패의 원인이라고 확정하거나 새 selector/PEFT 방법의 성능 PASS를 선언하지 않는다. ALL16 대비 유리하다는 결과에는 적은 검증 정보량이라는 차이도 남는다. 같은 두 seed·두 arm을 독립 데이터셋 12개로 세지 않는다.

이 결과에 맞춰 RECENT/SPREAD origin, 후보 학습률, 보정 강도를 다시 고르는 추가 탐색은 하지 않는다. 이후 방법 연구에서는 두 검증 배치와 F0/FIXED를 사전 고정 참조로 보존하고, 실제 학습 개입 자체의 추가 이득을 분리해야 한다. 구체적인 새 학습 계획은 이번 승인 범위에 포함하지 않았다.
