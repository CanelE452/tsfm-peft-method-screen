# 결과를 보기 전 고정한 해석 범위

날짜 먼저 선택 후 phase_k=floor(kP/n)를 사용하는 계약은 기간 전체의 날짜 다양성과 전체 phase 분포를 확보하지만, 날짜 순서와 목표 phase가 결정적으로 연결된다. 모든 계절·추세 구간에 모든 phase가 골고루 나타나는 완전 교차 설계는 아니다. 이 연결은 계약 그대로 유지하며 결과를 보고 재배치하지 않는다.

합법 후보의 first/last 날짜에 존재하는 phase가 제한되면 원형 거리 규칙상0이 선택될 수 있다. N01/R04/N07/R08 TRAIN의 phase0은4회, phase23은1회가 되어 차이3이다. 계약 한도2와 충돌하며 사전 BLOCKED_DIVERSITY다. 이번 실행에서는 이를 다른 tie 규칙이나 날짜 이동으로 교정하지 않는다.

N02/N03는 모든 다양성 기준을 통과했다. 날짜 다양성 확보는 예전 표본 집중을 제거하지만 새로운 데이터 원천이나 독립 test를 만든 것은 아니다. 교차 평가는 적격 트랙에서 동일 방법의 옛 가중치/새 원점 및 새 가중치/옛 원점을 비교하며, 단순 재평가 변화와 TRAIN/V 재학습·선택 효과를 부분적으로만 분리한다. 서로 다른 E의 점수 차이에 paired gain CI를 붙이지 않는다. 같은 E 위의 두 가중치 비교에만 paired index-block bootstrap을 사용할 수 있다.

명세상 표본 검사를 통과하지 못한 네 트랙은 GPU 교차 평가도 하지 않는다. old checkpoint 부재 때문이 아니며 BLOCKED_OLD_CHECKPOINT와 구분한다. 실행 시작 전 old selected checkpoint48개는 모두 해시가 일치했다.
