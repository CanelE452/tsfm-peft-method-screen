> 현재의 magnitude-aware residual restriction(MAG)을 추가하는 것이

현재 코드의 MAG:

- 추가 trainable parameters 8,712
- raw observation median/MAD 기반 robust scale
- patch16 내 `abs((x-m)/r) > 3` 비율
- `g_j = 1 - extreme_fraction_j`
- `h'_j = h_j + g_j * a_theta(h_j)`
를 그대로 사용한다.

# 0. 이번 실험의 과학적 위치

이 실험은 다음을 주장하려는 것이 아니다.

- MAG가 모든 TSFM에서 우수하다.
- LoRA가 수학적으로 반드시 선행되어야 한다.
- MAG가 실제 운영 사건의 원인을 식별한다.
- 큰 관측은 항상 보존해야 한다.
- MAG가 더 빠르다.
- Time-PEFT/PETSA/COSA 전체보다 우수하다.

검증하려는 것은 좁게 다음이다.

> 이미 적응된 전력 부하 예측기에 두 번째 소형 PEFT를 추가하는 설정에서,
> raw 관측의 robust magnitude 정보를 이용해 추가 residual을 제한하는 현재 MAG가
> 일반 residual adapter보다 실제 관측의 level-shift-like 구간에서 유용한가?

# 4. 실제 관측 level-shift 조건을 미래 target 없이 정의

이번 실험의 핵심이다.

E_CONFIRM의 각 legal origin o에 대해,
예측 직전의 512시간 context x만 사용한다.

최근 32시간:
`recent = x[-32:]`

그 이전 reference 128시간:
`reference = x[-160:-32]`

계산:
```
m_ref = median(reference)
m_recent = median(recent)
r_ref = max(
    1.4826 * median(abs(reference - m_ref)),
    0.1 * sigma_train
)

shift_score S = abs(m_recent - m_ref) / r_ref
```

이 정의에는 미래 y가 들어가지 않는다.

primary real-shift stratum:
`S >= 3.0`

secondary descriptive bins:
- `S < 1`
- `1 <= S < 2`
- `2 <= S < 3`
- `S >= 3`

threshold 3은 이번 결과를 보기 전에 고정한다.
E_CONFIRM에서 target error를 보고 threshold를 바꾸지 않는다.

중요:
- `S>=3`이 실제 운영 사건 label이라고 부르지 않는다.
- `observed large level-shift condition` 또는 `past-defined high-shift stratum`이라고 부른다.
- 미래가 실제로 계속 상승/하락하는지 여부는 조건 정의에 사용하지 않는다.
- 미래가 되돌아오는 경우도 그대로 채점한다.

## 4.1 표본 부족 규칙

E_CONFIRM의 `S>=3`에:
- unique UTC dates가 14일 미만이거나
- eligible origins가 50개 미만이면

primary stratum을 더 낮은 threshold로 재정의하지 않는다.

`INSUFFICIENT_REAL_SHIFT_COVERAGE`
를 기록하고:
- 전체 raw performance
- 사전 정의된 S bins
를 기술적으로 보고한 뒤,
MAG 방법 성공/실패를 강하게 판정하지 않는다.

새 source를 성능 때문에 추가하지 않는다.

# 5. 학습 방법은 현재 MAG 논문 설정을 그대로 이식

새 dataset에서 방법 자체를 재현하기 위해
NYISO TRAIN/V로 source-specific models를 학습한다.

## 5.1 F0

pinned `amazon/chronos-bolt-small`
- no adaptation
- evaluation baseline only

## 5.2 B0 = LoRA first-stage

현재 B0와 동일한 구조:
- q/v rank 8 LoRA
- alpha 등 현재 실제 B0 설정을 repo에서 읽어 그대로 사용
- backbone의 나머지 부분 freeze
- raw input pathway 유지

**현재 B0를 만드는 실제 training recipe를 그대로 복제**한다.
파라미터 수가 294,912인지 actual model에서 assert.

B0 TRAIN augmentation/loss/update/selection도 현재 B0의 실제 계약을 그대로 가져온다.
새로운 augmentation state나 loss를 만들지 않는다.

selection:
- seed `92100`
- 기존 B0에서 사용한 LR 후보만 재사용
- V_SELECT에서 현재 B0 selection objective 그대로 사용

repeat:
- `92101`, `92102`

각 repeat는 selection에서 고정한 LR을 사용하되
자기 checkpoint step은 자기 V_SELECT로 기존 규칙대로 선택한다.

## 5.3 B0_PLAIN

각 seed의 selected B0를 freeze.

기존 PLAIN과 동일:
- ResidualAdapter 512→8→512
- 8,712 params
- gate=1
- zero-output init
- step0 prediction = B0 exact

TRAIN augmentation / loss / updates / checkpoint / LR grid / V selection
전부 현재 B0_PLAIN 계약 그대로.

## 5.4 B0_MAG

각 seed의 동일 selected B0를 freeze.

기존 MAG를 그대로 사용:
- 같은 ResidualAdapter
- 같은 initialization
- 같은 8,712 params
- median/MAD/floor0.1sigma/threshold3/patch16 고정
- raw input clipping 없음
- MAG gate만 PLAIN과 다름
- step0 prediction = 같은 B0 exact

**MAG 수식 변경 금지.**

## 5.5 단순 보정 대조 — OUTPUT_CONTEXT

현재 저장소의 기존 `OUTPUT_CONTEXT` 구현을
변경 없이 같은 B0에 붙인다.

역할:
- 내부 patch magnitude restriction이 아니어도
  작은 output-space correction으로 충분한지 보는 보조 대조.

파라미터 수와 정보 권한을 그대로 기록.
이 대조가 다른 논문의 공식 전체 방법이라고 부르지 않는다.

# 6. 학습 예산

정확한 현재 historical contract를 먼저 확인하고,
아래 상한보다 **더 많이** 돌리지 않는다.

B0:
- selection seed × existing LR grid
- repeat seeds 2개

PLAIN:
- selection seed × existing LR grid
- repeat seeds 2개

MAG:
- selection seed × existing LR grid
- repeat seeds 2개

OUTPUT_CONTEXT:
- selection seed × existing LR grid
- repeat seeds 2개

현재처럼 LR grid가 2개라면:
- 각 family 4 fits
- 총 16 fits

각 fit 1,024 updates라면:
- 총 main update cap = 16,384

실제 historical B0/adapter 계약이 다르면
**historical contract를 우선**하고,
실행 전에 `TRAINING_BUDGET.json`에 계산된 fit/update 상한을 봉인한다.

새 LR, 새 seed, 새 update budget은 결과를 보고 추가하지 않는다.

smoke는 family/source/architecture별 최소 실제 gradient 연결 확인에만 사용.
smoke optimizer updates도 별도 cap을 봉인.

# 11. 이번 프로젝트용 계속/중단 결정 규칙

이 규칙은 과학적 법칙이 아니라
**빠른 방법론 논문 목표에서 추가 투자를 결정하기 위한 project rule**이다.

## CONTINUE_MAG_METHOD_TOPIC

다음을 모두 만족하면 권고:
1. primary `S>=3`에서 MAG vs PLAIN 평균 gain > 0
2. 두 repeat seed 모두 gain >= 0, 적어도 하나는 > 0
3. 전체 raw E_CONFIRM에서 MAG가 PLAIN보다 1% 초과 악화하지 않음
4. primary gain이 output correction 하나만으로 완전히 설명되지 않음
   - 즉 MAG vs OUTPUT_CONTEXT도 방향과 효과 크기를 함께 보고 판단
5. 실제 raw target을 사용한 결과임을 유지

CI가 0을 포함한다고 자동 FAIL로 만들지 않는다.
다만 효과가 매우 작고 불확실하면 `WEAK_CONTINUE`로 따로 표시.

## STOP_MAG_AS_PRIMARY_METHOD_TOPIC

아래 중 핵심 하나가 확인되면 권고:
- primary `S>=3`에서 MAG <= PLAIN
- MAG의 이득이 실제 raw 조건에서는 사라지고 synthetic 결과에만 남음
- OUTPUT_CONTEXT 같은 더 단순한 보정이 동일/더 좋은 결과를 내며 MAG의 고유 실용가치가 없음
- 전체 raw 손해가 목표조건 이득보다 실용적으로 더 커서 사용 가정이 설득되지 않음

STOP이면:
- 새 gate
- threshold tuning
- rank 변경
- 새 source shopping
- 추가 seed rescue
를 자동으로 시작하지 않는다.

기존 positive synthetic results는 삭제하지 않고
`development stress-test evidence`로 보존한다.

## INCONCLUSIVE_DATA_COVERAGE

실제 high-shift observation이 너무 적으면:
- MAG 성공/실패를 강제로 판정하지 않음
- 다른 threshold로 rescue하지 않음
- 데이터 부족을 명시

# 15. 현재 선행과의 연결

문서에는 다음 경계를 유지한다.

Time-PEFT:
- LoRA + frequency/channel adapters를 함께 학습하는 다른 설정
- 우리 MAG가 Time-PEFT보다 우수하다고 이번 실험으로 주장하지 않음

MSFT:
- multi-scale 특화 adaptation과 다른 문제

AdaPTS:
- multivariate adaptation과 다른 문제

δ-Adapter / COSA:
- frozen predictor를 보강하는 가까운 큰 연구 설정
- 정보 권한 / intervention 위치가 다름

현재 MAG의 주장은:
- `already-adapted forecaster`
- `second-stage small residual`
- `observation magnitude-aware restriction`
의 **구체적인 조건부 추가 가치**에 한정.
