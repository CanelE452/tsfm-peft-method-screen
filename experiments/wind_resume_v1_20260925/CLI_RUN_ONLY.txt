작업 유형: 작성자가 허용한 wind 전용 1회 재개·결과 push. 코드 수정 금지.

대상은 실제 실행된 topic_axis_gonogo_v1_20260925다. domain_axis 패키지로 바꾸지 않는다.
기존 topic_axis의 .started 파일, experiments 폴더, 최초 결과는 삭제·이동·수정하지 않는다.
이번 실행은 실패한 다운로드 선정 뒤 데이터 경로가 확보돼 허용한 wind 전용 재개다.
기존 세 주제 전체를 재실행하라는 승인이 아니다.

1. 새 ZIP을 저장소 밖 새 폴더에 압축 해제한다. 기존 원본과 실패 증거는 보존한다.
2. 실제 CanelE452/tsfm-peft-method-screen 저장소 루트에서 다음 명령을 한 번 실행한다.

python3 -B /실제/압축해제경로/wind_resume_v1_20260925/run.py --repo "$PWD" --publish \
  --wind-csv "$PWD/.cache/sdwpf_20260925/sdwpf_245days_v1.csv" \
  --wind-locations "$PWD/.cache/sdwpf_20260925/sdwpf_baidukddcup2022_turb_location.csv"

3. .py, ENGINE_PIN.json, manifest, 원래 RUN_CONFIG.json을 수정하지 않는다.
4. 실행기는 원래 코드/설정 해시, 최초 wind 차단 이유, 원래 잠금, 공식 캐시 MD5와 입력 크기를 확인한다.
   하나라도 맞지 않으면 그대로 중단해 오류를 반환한다. 이름 변경/재다운로드/설치/우회 금지.
5. 원래 triage.worker의 wind만 호출한다. 원래 run.py를 호출하지 않는다.
   respiration/coordinates 실행 0회. wind 계산 상한은 원래대로 900초다.
6. 출력은 새 results/wind_resume_v1_20260925/run_<UTC>/에 남긴다.
   원자료와 모델은 Git에 넣지 않고 새 실행기·작은 로그/결과만 자동 commit·push한다.
7. 실패해도 성공시키려고 코드를 수정하거나 재실행하지 않는다.
   새 승인 토큰도 1회만 유효하다. 예전/새 잠금 삭제 금지.
8. Git 원격 변경/인증/기존 staged 변경은 자동 수정하지 않는다.
   force push/pull/rebase/reset/git add . 금지. 기록된 receipt만 반환한다.
9. CLI는 과학적 해석을 하지 않는다. 종료 후 다음만 전달한다.
   - 실행 명령, 종료 코드
   - .cache/wind_resume_v1_20260925/EXECUTION_RECEIPT.json 내용
   - commit SHA, push 상태, result 상대경로
   - wind axis_status, action, reason 원문
   - 처음 실패했다면 LAST_PRECONDITION_FAILURE.json

종료코드 0이나 PUSH_VERIFIED는 과학적 GO가 아니다.
이번 wind 결과는 최초로 실행된 wind 계산이며, 이전 차단 기록을 독립 재현으로 세지 않는다.
