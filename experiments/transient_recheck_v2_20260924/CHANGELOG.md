# v2의 변경과 해석 제한

이 패키지는 v1 clean ZIP의 패키징만 다시 하는 작업이 아니다. 명시적으로 다른 재평가 계약이다.

- 바뀜: context 밖 접근 제거, 확정 계획 공통 제공, 명령 일정 hash/적용시각 검사.
- 바뀜: 학습 episode별 정규화+시간순 nested alpha 선택. alpha=1 결과도 유지.
- 바뀜: 요약 이력만이 아니라 표준 시차 이력 회귀를 작은 추가 대조로 사용.
- 바뀜: 전체 평균 외 명령 전환 패널별/날짜별 보고. 물리적 정착으로 이름 붙이지 않음.
- 바뀜: 좋은 한 target을 고르는 gate 폐기. 다섯 과제 모두 동일 계약으로 보고.
- 바뀜: 실행 상태와 과학적 판정 분리. 완료라고 정보가 확인되거나 PEFT로 자동 진행하지 않음.
- 유지: 기존 다섯 target/horizon, 원점 위상(완전한 context 없는 최초 원점만 제외), 원자료 분할.
- 유지: reserve7 미열람. 새 데이터 수집 및 neural 학습 없음. 이전 수치 보존.
- 패키징: 소스만 묶고 .pyc/__pycache__ 제외. -B/PYTHONDONTWRITEBYTECODE=1. 마지막 파일 변경 뒤 manifest 생성.

여러 계약을 동시에 정정하므로 v1과 v2 수치 차이를 특정 한 수정의 인과 효과라고 표현하지 않는다.
이번 수정은 결과를 본 뒤의 후향적 재검증이다. '사전 확증 실험이 통과했다'고 표현하지 않는다.
