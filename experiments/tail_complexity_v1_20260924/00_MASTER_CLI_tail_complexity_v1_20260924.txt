0. 목적과 판정 구조
======================================================================

최상위 목적: TSFM PEFT 방법론 논문 (Time-PEFT식 "난이도 정의 → 측정 → 격차 확인 → 메커니즘 → 방법").
이번 단계: 난이도 정의 자체의 타당성 검증. 방법 설계는 이 판정이 TC_VALID일 때만 연다.

난이도 후보 (하나):
  꼬리 복잡도 = 꼬리 두께 ξ(일반화 파레토 분포 GPD의 모양 모수) + 극단 군집 1−θ(θ = 극단지수)
  둘 다 학습 구간만으로 추정한다.

"난이도로 성립한다"의 조작적 정의 — 다섯 가설 전부 (§7):
  H1 측정 가능성   학습 구간만으로 안정적으로 추정된다
  H2 비중복성      Time-PEFT의 스펙트럼 엔트로피(SE)로 설명되지 않는다
  H3 예측 타당성   SE를 통제하고도, 단순 꼬리 확장 뒤에 남는 격차를 예측한다 (F0와 LoRA 모두)
  H4 메커니즘 정합  그 예측력이 격자 안(0.95)보다 격자 밖(0.995)에서 크다
  H5 실익          고난이도 계열에서 남는 격차가 실질적 크기다

결과별 해석 (실행 전 고정):
  TC_VALID         합성·실데이터 모두 H1–H5 통과. 방법 단계(조건부 EVT 헤드) 설계로 간다(사용자 승인 후).
  TC_UNSTABLE      H1 실패. 추정량이 불안정해 난이도 지표로 쓸 수 없다.
  TC_REDUNDANT     H2 실패 또는 H3의 증분 설명력 미달. SE(=Time-PEFT 축)로 설명된다. 주제 종료.
  TC_NO_GAP        H5 실패. 단순 꼬리 확장만으로 충분하다. PEFT가 필요 없다. 주제 종료.
  TC_SYNTH_ONLY    합성은 통과, 실데이터는 실패. 금융에서는 실익이 없다는 뜻. 전력가격(S3)으로 한 번 더 본 뒤 결정.
  STOP_DEBUG       S0 실패. 과학적 판정 없음.
  INCONCLUSIVE_*   표본·추정 불가 등으로 판정 불가.

2. 표준과의 차이 (선행 확인 결과)
======================================================================
- 꼬리 모수 추정: GPD 초과분 최우추정(peaks-over-threshold)과 극단지수의 intervals 추정량은 표준이다
  ("Inference for clusters of extreme values", JRSS-B 2003). 새로 만든 지표가 아니라 표준 추정량을
  "TSFM PEFT 난이도"로 쓰는 것이 이번의 새로움이다.
- 실데이터 기준 모델: 조건부 EVT
  ("Estimation of tail-related risk measures for heteroscedastic financial time series: an extreme value approach",
   J. Empirical Finance 2000)와 GARCH-t. 금융 꼬리 예측의 표준 기준선이다.
- 평가: 분위수 점수(pinball)와 초과율. 중앙값 기반 점예측 지표는 쓰지 않는다
  (v1·v2에서 점예측 추출이 결론을 바꾼 교훈).
- SE 정의: Time-PEFT 본문의 정의를 확인해 그대로 쓴다(§3 Q5). 확인 못 하면 표준 정규화 스펙트럼 엔트로피를 쓰고 기록.

4.1 S1 합성 (오라클이 정확히 알려진 통제 실험) [결정]
  y_t = sin(2πt/24) + x_t
  x_t = φ·x_{t−1} + σ_t·ε_t
  σ_t² = ω + a·(σ_{t−1}ε_{t−1})² + b·σ_{t−1}²,  ω = 1 − a − b   (무조건 분산 1로 고정)
  요인 (2 × 3 × 2 = 12 조건):
    φ ∈ {0.5, 0.9}
    ε ∈ {Gaussian, 표준화 t(ν=6), 표준화 t(ν=3.5)}          (단위 분산으로 표준화)
    GARCH ∈ {off: a=b=0, on: a=0.10, b=0.85}
  조건당 40계열, 길이 4,000 (학습 3,000 / 평가 1,000), 번인 1,000 버림. seed 20260924 + 조건·계열 번호.
  학습 구간 3,000은 다시 FIT(앞 2,500)와 CAL(뒤 500)으로 나눈다. LORA 학습은 FIT만,
  EVT-S 적합과 SEL 선택은 CAL만 쓴다(LoRA가 본 표적으로 꼬리를 보정하지 않기 위해).
  난이도 측정(§5)은 학습 구간 3,000 전체를 쓴다.
  평가 원점: 평가 구간에서 5 step 간격 → 계열당 200원점. 예측 길이 h = 1.
  오라클 (h = 1, 정확): q_τ = sin(2π(t+1)/24) + φ·x_t + σ_{t+1}·F_ε^{-1}(τ)
    (σ_{t+1}은 시뮬레이터가 저장한 σ_t, ε_t로 계산)
  "참값" ξ_true, θ_true: 같은 조건으로 길이 2,000,000 계열을 만들어 §5와 같은 절차(같은 임계 분위수)로 추정.
  같은 φ 안에서는 ε·GARCH가 달라도 σ_tε_t가 단위 분산 백색잡음이라 y의 자기공분산(=스펙트럼)이 같다.
  이것이 H2의 "스펙트럼 일치 쌍"이다.

5. 난이도 측정 (학습 구간만 사용. 봉인 대상)
======================================================================

5.1 잔차
  S1: 학습 구간에서 AR(p) 최소제곱 적합, p = P + 1 (P = 학습 구간 주기도의 우세 주기. 기대값 24 → p = 25).
      r_t = 잔차 / MAD(잔차).
  S2: r_t = (L_t − median_TRAIN(L)) / MAD_TRAIN(L)   (일수익률은 선형 구조가 약해 필터를 두지 않음) [결정]
  잔차에서 재는 이유: AR 지속성 때문에 생기는 수준의 군집은 조건부 평균이 이미 설명한다.
  여기서 재려는 것은 예측할 수 없는 충격의 꼬리 두께와 그 충격끼리의 군집(변동성 군집)이다.
5.2 꼬리 두께 ξ̂
  u = r의 0.95 분위수(학습 구간). 초과분 r − u (r > u)에 GPD 최우추정(위치 0 고정).
  초과분 < 50개면 NA.
5.3 극단지수 θ̂ (intervals 추정량, 임계 u 동일)
  N = 초과 횟수, T_i = 연속 초과 사이 간격 (i = 1..N−1).
  max T_i ≤ 2 이면 θ̂ = min(1, 2(ΣT_i)² / ((N−1)·ΣT_i²))
  아니면      θ̂ = min(1, 2(Σ(T_i−1))² / ((N−1)·Σ(T_i−1)(T_i−2)))
  (Q2에서 원문 대조)
5.4 스펙트럼 엔트로피 SE: Q5 결과의 정의. 보조로 잔차 SE도 계산.
5.5 보조: 초과 첨도.
5.6 합성 난이도 순위 TC_rank = (ξ̂ 순위 + (1−θ̂) 순위)/2 — H5의 삼분위에만 쓴다.

6. arm과 평가
======================================================================

6.1 예측 arm
  F0     Chronos-2 zero-shot, context 512, bf16, 학습 분위수 21개 요청
  LORA   Chronos2Pipeline.fit(finetune_mode="lora") [v2 §2.3 확인된 배선]
         lora_config = None(기본값 기록), prediction_length = 1, context_length = 512,
         learning_rate = 1e-5, num_steps = 1000, batch_size = 32, validation_inputs = None,
         extra_trainer_kwargs: save_strategy = "no", seed = s; fit 직전 torch.manual_seed(s).
         S1: 조건마다 1 fit(해당 조건 40계열의 FIT 구간), seed 0 → 12 fits.
         S2: 전 종목 TRAIN 구간 풀링 1 모델, seed ∈ {0, 1} → 2 fits. 두 seed는 따로 채점하고 계열별 G를 평균한다.
  참조   S1: 오라클(§4.1).
         S2: GARCH-t (AR(1)-GARCH(1,1), t 분포), 조건부 EVT (AR(1)-GARCH(1,1) QML 필터 + 표준화 잔차의
             상위 10% GPD). 둘 다 1,000일 이동창으로 매월 첫 거래일 재적합. 주 참조 = 조건부 EVT.

6.2 격자 밖 확장 (F0·LORA 각각에 적용, 학습 없음)
  CLAMP   패키지 기본 동작(0.995·0.999 = 0.99 값). 참고용.
  LIN     정규 꼬리 외삽: q_τ = q_.99 + (Φ⁻¹(τ) − Φ⁻¹(.99))·(q_.99 − q_.95)/(Φ⁻¹(.99) − Φ⁻¹(.95))
  EVT-S   정적 EVT: CAL 구간(S1은 §4.1의 CAL 500 step, S2는 2017–2018)에서 같은 모델로 롤링 예측해
          z = (y − q_.5)/(q_.9 − q_.1) 계산, z의 0.95 분위수 초과분에 GPD 적합(고정).
          q_τ = q_.5 + (q_.9 − q_.1)·z_τ  (τ > 0.99에만 적용)
  SEL     LIN과 EVT-S 중 CAL의 τ = 0.995 분위수 점수가 낮은 쪽 (arm·계열 단위로 CAL에서 선택. TEST 선택 금지).
  격자 안 수준(0.95, 0.99)은 확장 없이 모델 출력 그대로.

6.3 지표
  분위수 점수 QS_τ(q, y) = (1{y < q} − τ)(q − y),  τ ∈ {0.9, 0.95, 0.99, 0.995, 0.999}
  격차 G_τ(arm) = mean_origin QS_arm / mean_origin QS_ref − 1   (계열 단위)
  주 지표: G*_.995 = SEL 확장을 적용한 arm의 G_.995.  보조: G*_.999, G_.95, G_.9, 초과율(τ별).
  τ = 0.999는 초과가 드물어 보조로만 쓴다.

6.4 통계
  S1 단위 = 계열(480). 조건별 층화 부트스트랩 2,000회.
  S2 단위 = 종목. 종목 부트스트랩 2,000회.
  회귀 (계열/종목 단위, OLS):
    M0: log(1 + G*_.995) ~ SE
    M1: log(1 + G*_.995) ~ SE + ξ̂ + (1−θ̂)
    증분 설명력 ΔR² = R²(M1) − R²(M0), 부트스트랩 CI.
  S1 추가: 같은 회귀를 ξ_true, θ_true로도 돌려 추정량 잡음의 영향을 본다(보고 전용).


======================================================================
7. 가설과 판정 기준 [제안값 — 봉인 전 확정]
======================================================================
H1 측정 가능성
  S1: Spearman(ξ̂, ξ_true) ≥ 0.8, Spearman(θ̂, θ_true) ≥ 0.6 (계열 단위, 12조건 전체).
  S2: 반분 신뢰도 — TRAIN 전반(2005–2010)과 후반(2011–2016)의 ξ̂, θ̂ 각각 Spearman ≥ 0.5.
H2 비중복성
  S1: 스펙트럼 일치 쌍(같은 φ)에서 평균 ΔSE의 95% CI가 0을 포함하거나 |평균 ΔSE| < 0.01 (체계적 차이 없음),
      그리고 평균 Δξ̂의 95% CI가 0을 포함하지 않음.
  S2: |Spearman(SE, ξ̂)| < 0.3 그리고 |Spearman(SE, 1−θ̂)| < 0.3.
H3 예측 타당성 (F0와 LORA 각각, S1·S2 각각)
  M1에서 ξ̂ 또는 (1−θ̂) 계수 중 하나 이상이 양수이고 95% CI 하한 > 0, 그리고 ΔR² ≥ 0.10.
H4 메커니즘 정합 (F0, S1·S2)
  τ = 0.995 회귀의 ξ̂ 계수 − τ = 0.95 회귀의 ξ̂ 계수 > 0, 부트스트랩 CI 하한 > 0.
H5 실익 (F0와 LORA 각각)
  TC_rank 상위 삼분위의 G*_.995 중앙값 ≥ 0.10, 하위 삼분위 ≤ 0.05.
  (근거: 상위 난이도에서 단순 확장이 참조보다 10% 이상 나쁘지 않으면 새 모듈의 여지가 작다고 본다)

판정 순서: S0 → H1 → H2 → H3 → H4 → H5. 앞 가설이 실패하면 뒤는 보고만 하고 판정은 그 실패로 한다.
TC_VALID는 S1과 S2 모두 전부 통과해야 한다. S1만 통과면 TC_SYNTH_ONLY.

11. 이 계획이 틀렸다면 어디서 틀렸을까
======================================================================
가장 약한 고리 — 변동성 추적과 꼬리 모양의 교란:
  GARCH 조건에서는 F0가 조건부 척도(변동성)를 못 따라가서 τ = 0.9에서도 이미 격차가 클 수 있다.
  그러면 ξ̂·θ̂의 예측력이 "꼬리"가 아니라 "변동성 추적 실패"에서 올 수 있다.
  H4(격자 안보다 격자 밖에서 효과가 큰가)와 G_.9 보고가 이것을 가른다. H4가 실패하면 꼬리 복잡도라고 부르면 안 된다.
둘째 — 참조의 강도: S2의 조건부 EVT가 약하면 G가 과소평가되고, 너무 강하면 모든 arm이 진 것처럼 보인다.
  GARCH-t를 함께 보고해 참조 선택의 민감도를 드러낸다.
셋째 — 0.995·0.999의 표본 부족: 계열당 평가 원점이 200(S1)·약 1,600(S2)이라 0.999 초과는 계열당 0.2~1.6개다.
  그래서 주 지표를 0.995로 두고 0.999는 보조로만 쓴다.
넷째 — 생존 편향(S2): 현재 구성종목만 쓰므로 꼬리가 가장 무거웠던 퇴출 종목이 빠진다. 난이도 범위가 좁아져
  H3 검정력이 떨어지는 방향이다.
다섯째 — SE 정의(Q5): Time-PEFT의 정확한 정의를 못 찾으면 "Time-PEFT 축과 독립"이라는 주장은 약해진다.
