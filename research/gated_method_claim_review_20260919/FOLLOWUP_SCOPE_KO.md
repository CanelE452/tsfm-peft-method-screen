# 후속 검증의 범위 검토안 — 실행 계약 아님

상태: **범위 변경 확인 대기**. 기존 사용자 지시의 ‘새 후보·후속 학습 자동 시작 금지’를 유지한다. 현재까지 새 학습0회다. 이 문서를 승인된 실험·봉인된 명세·실제 runner라고 표시하지 않는다.

## 결정할 범위

추천하는 단일 방향은 **기존 MAG_ONLY를 변경 없이 고정하고, 같은 위치의 학습형 gate로 충분한지 확인하는 것**이다. C3 지속성 규칙을 살리기 위한 재튜닝은 제외한다. MAG를 정식 후보로 승격하는 결정은 과거 E를 본 뒤 이루어졌다고 공개한다. 과거 결과를 사전 확증으로 바꾸지 않는다.

기존 B0/PLAIN/C3/MAG/POS_ONLY의 checkpoint와 점수는 해시로 재사용한다. 새 대조는 두 개 이내: 동일 residual의 학습형 sigmoid token gate와 그 entropy-regularized 변형. 둘은 가까운 gating 원리의 대조이며 새 제안 후보가 아니다. 공식 GateRA 전체의 성능 재현으로 부르지 않는다.

## 최대 예산 제안과 공정성

상한 제안은 **16개 본학습 경로 /16,384 updates +8 smoke updates**다. 두 원천×두 gate 대조×selection seed81550의 두LR=8경로, 선택LR의 seed81551/81552 반복=8경로다. 기존 MAG의 세 번째 seed 결과를 삭제하지 않되 새 직접 비교의 두 공통 seed와 분리한다. 기존 raw TRAIN draws·labels·512→64·Chronos-Bolt-small·FP32·batch32·1024updates·다섯checkpoint·V목적·LR grid를 유지한다.

학습형 gate의 초기값, entropy 계수 및 단위, 추가 파라미터 예산, 원문 대비 변경을 **실행 전** 별도 계약에 정확히 고정해야 한다. 현재 원문 검토만으로 모든 공식 구현 세부가 확인된 것은 아니므로 이 문서는 실행 준비 완료가 아니다. 결과를 본 뒤 계수를 바꾸지 않는다. gated branch 이식의 CPU식 검사와 실제 Chronos off/B0 동일성·동결 보존·복원 smoke가 별도로 필요하다.

## 확인할 평가 범위

기존 Electricity/ETTm1 E는 개발 비교로만 재사용한다. 이번 주장을 확인할 새 기간은 기존 평가 origin·target·문맥과 자료 노출 이력을 감사한 뒤 미리 고정한다. NESO2026 H1은 `results/c3_identifiability_temporal_20260918/DATA_MANIFEST.json`에 이미 평가 완료로 기록돼 있으므로 다시 독립 평가로 사용하지 않는다. 해당 CSV는2026년 파일 전체가 내려받아졌으며, 아직 평가하지 않은 후반 기간이라도 raw 자료 미접촉이라고 단정할 수 없다.

구체적인 새 기간과 origin 수는 아직 봉인하지 않았다. 충분한 서로 다른 날짜와 기간 범위가 없으면 날짜 중복으로 표본 수를 채우거나 평가 구간을 결과에 맞춰 바꾸지 않는다. 새 기간을 평가하기 전에 metadata 기반 가용성·노출 감사와 전체 계획을 확정해야 한다. 같은 국가 집계계열의 후반 기간은 독립 source 증거를 대신하지 못한다.

## 종료 규칙

추가 비교에서 기존 MAG의 의미 있는 구성요소 이득이 확인되지 않으면 이 방향을 종료한다. 우위가 있는 경우에도 좁은 예측 효과, 원자료·오류·형태별 손해, 자원 비용, 새 기간의 재현 여부, 신규성을 따로 적는다. 성능 기준·보호 허용오차·주 비교 family는 실행 전 확정하고, 유리한 결과를 본 뒤 만들지 않는다. 이 문서에는 새 PASS 기준을 사후 부여하지 않았다.

정식 실행 명세와 구현을 완성한 뒤 승인 범위 내에서만 실행하며, 예산 종료 후 다른 후보·추가 seed·LR·dataset을 연결하지 않는다. 현재 질문에 대한 답변이 없으면 GPU 작업을 시작하지 않는다.
