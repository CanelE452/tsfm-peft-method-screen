# 예보 신뢰도 진단 — 다음 PEFT 가설의 근거와 반례

[확인] **예보가 서로 다르면 날씨를 차단한다는 단순 gate를 다음 방법으로 확정할 근거는 부족하다.** 같은 예보 경로의 기상 오차와 부하 예측 손해는 다르게 움직였다. 이번에 기존 28개 원점의 저장된 네 경로 예측을 분석했고, 신규 학습·모델 예측·GPU 사용은 모두 0이다. 이전 참조 비교의 판정을 변경하지 않았다.

[설계] 남겨 둘 문제는 **“미래 예보의 품질이 달라져도 유용한 외생정보를 유지하는 PEFT”**다. 아직 새로운 적응 규칙을 확보한 것은 아니다. 아래 진단은 어떤 신호를 곧바로 규칙으로 삼으면 안 되는지 밝힌 것이며 PEFT 성능 PASS가 아니다.

## 실제로 분리한 것

이전 참조 실행의 C12원점(3~5월), D16원점(6~9월)을 그대로 사용했다. D는 이미 노출된 탐색 구간이다. input spread는 네 예보 경로의 표준편차를 해당 과거 기상 표준편차로 나눠 세 변수·24시간 평균한 값이다. output spread는 네 부하 median 예측의 불일치다. DAMAGE는 `LATEST primary − F0 primary`이며 양수일 때 날씨 입력이 부하 예측에 손해다. [계산 전 범위](SCOPE.md).

기상 오차 proxy는 dataset의 weather_measurements와 예보의 차이를 같은 과거 기상 척도로 나눈 절대 오차다. 이 값은 **사후 진단용**이다. 공개시각이 없으므로 온라인 입력으로 사용하지 않았고, 해당 파일을 정확한 현장 관측 참값으로 단정하지 않았다. 새로운 기상 데이터를 다운로드하거나 모델에 oracle 입력을 넣지 않았다.

## 기상 오차와 최종 손실이 일치하지 않았다

| 구간 | 미래 경로 | 부하 Primary | 기상 오차 proxy |
|---|---|---:|---:|
| C | 최신 k0 | 0.185512 | 0.189003 |
| C | k1 | 0.194686 | 0.246884 |
| C | k2 | 0.189897 | 0.310643 |
| C | 가장 오래된 k3 | 0.233075 | 0.383000 |
| D | 최신 k0 | 0.149479 | 0.318291 |
| D | k1 | 0.153017 | 0.240321 |

[확인] D에서는 k1의 기상 오차 proxy가 k0보다 작지만 부하 Primary는 더 나빴다. 오래된 k3를 쓰면 평균 부하 손실이 C에서 0.047563, D에서 0.027682 증가했고, D의 16원점 중11개에서 나빴다. 실제 예보 품질 변화에 대한 취약성은 관찰됐지만, 세 변수의 평균 기상 오차가 곧 부하 예측 손해를 결정한다는 주장은 지지되지 않았다. [112개 경로 원점수](path_scores.csv), [경로 요약](path_summary.csv), [짝 비교](paired_age_summary.json).

[추정] 변수별 경제적 영향·시간대·예보 편향·모델의 조건부 반응이 다를 수 있다. 현재 집계만으로 어느 설명을 원인으로 확정하지 않는다. 특히 k0와 k1의 기상 오차 순위 역전을 정답 경로 선택기로 사용하지 않았다.

## 원점에 가용한 불일치 신호도 충분하지 않았다

| 신호와 결과의 Spearman 상관 | C12 | D16 |
|---|---:|---:|
| 입력 예보 불일치 / DAMAGE | 0.5315 | 0.2147 |
| 부하 출력 불일치 / DAMAGE | 0.0420 | 0.0265 |
| 기상 오차 proxy / DAMAGE | 0.0699 | 0.2941 |
| 입력 예보 불일치 / 혼합 이득 | 0.3706 | -0.0853 |
| 부하 출력 불일치 / 혼합 이득 | 0.1399 | -0.2618 |
| 기상 오차 proxy / 혼합 이득 | 0.3217 | 0.0147 |

소수의 이미 노출된 원점을 사용한 기술 통계다. 유의성이나 일반화 성능을 주장하지 않는다. 기상 오차 proxy는 미래를 본 진단이고 output spread는 네 모델 경로 실행을 필요로 하므로 무료 입력 신호도 아니다. [전체 상관](correlations.csv).

입력 불일치의 C중앙값 0.216466으로 low/high를 고정했을 때 D에서는 low3개, high13개로 분포가 바뀌었다. high에서도 최신 기상 사용의 평균 Primary는 **0.148347**, F0는 **0.169632**로 기상 입력이 여전히 유용했다. high13개 중5개에서는 손해였지만 나머지의 이득도 존재했다. 따라서 high를 전부 차단해야 한다는 설명은 현재 집계와 맞지 않는다. 이 집계를 이용한 새 fallback 정책은 계산하거나 배포하지 않았다. [집단별 원점수](cohorts.csv).

또 C12개에서는 최신 기상이 F0보다 나쁜 원점이 0개였고, D16개에서는 5개였다. **C의 최신 경로만으로 '해로운 예보를 탐지하는 선택기'를 학습할 때, 실제 손해 사례가 없다는 제약**이 있다. 손해 여부 이진 분류의 이야기이며, 연속 손실 회귀나 다른 학습의 불가능성까지 입증하지 않는다.

## 선행과 연결한 다음 판단

공변량 선택과 경량 조건화는 CoRA·UniCA에서, 소수 호출을 통한 과거 기반 출력 적응은 TFMAdapter에서 이미 다룬다. Exogenous Dropout은 단순 채널 드롭아웃을 복잡한 gated FiLM/fallback 구조에도 똑같이 적용했을 때의 강한 대조를 제공한다. 각 방법의 실제 확인 범위와 원문 링크는 [선행 경계](LITERATURE_BOUNDARY.md)에 기록했다. 이러한 기존 방법을 모두 실행해 이겼다는 뜻은 아니다.

[설계] 앞으로 방법을 판단할 때에는 일반 LoRA, 같은 조건의 공변량 dropout, 실제 가용한 과거 예보 버전을 이용한 학습 대조가 필요하다. 세 비교를 통해 **적응 자체의 가치**, **일반 손상 노출의 가치**, **예보 버전 정보의 추가 가치**를 분리할 수 있다. 버전 augmentation만 좋으면 알려진 학습 데이터 변경의 유용성으로 기록해야 하고, 그것만으로 새 PEFT 방법론은 아니다.

이 단계에서 새로운 gate를 학습하거나 이전 mixture를 teacher로 강제로 선택하지 않는다. 다음 실제 학습에 들어가려면 같은 정보·파라미터·학습 기회의 대조와, 그 대조가 설명하지 못하는 구체적인 적응 규칙을 먼저 명세해야 한다. 지금 남은 핵심은 **예보 오차 크기를 추종하는 대신 최종 부하 예측에 유익한 변화와 해로운 변화를 구분할 수 있는가**다. 이를 해결하는 새 메커니즘과 독립 예측 이득은 미확보다. 연구 문제를 좁힌 것과 방법론 PASS를 구분한다.
