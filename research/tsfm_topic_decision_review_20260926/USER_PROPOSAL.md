# TSFM 주제 잠정 선택안 — 2026-09-26

상태: 계획 합의용 제안. 새 학습이나 실험을 실행한 결과가 아님.

## 1. 잠정 주제

**채널 압축의 정보 손실을 보완하는 경량 다변량 TSFM 적응**

연구 질문: 동결된 시계열 파운데이션 모델(TSFM)에 입력하는 잠재 채널 수를 제한할 때, 압축에서 남은 과거 성분을 작은 시간 예측 모듈로 처리하는 것이, 잠재 채널 수를 늘리거나 원자료에 작은 예측기를 병렬로 붙이는 것보다 정확도–실제 추론비용에서 유리한가?

방법 후보와 효과는 [추정·미검증]. 채널 압축, 공통·개별 성분 분해, 잔차 연결 자체의 신규성은 주장하지 않는다. 대형 모델 가중치는 고정하고 입력·출력 변환 및 작은 시간 모듈만 학습하는 효율적 적응 범위를 유지한다.

목적: 민재가 이 질문을 방법 연구의 주력으로 선택할지 결정한다. 새로운 복잡도 점수, 온라인 의존성 추정, 계열별 선택기 연구로 자동 변경하지 않는다.

## 2. 선택 근거와 반대 근거

[확인] AdaPTS: Adapting Univariate Foundation Models to Probabilistic Multivariate Time Series Forecasting(2025/ICML)은 특징 공간을 변환하고 잠재 차원별로 동결 모델을 적용하는 적응 틀을 제시한다. 공식 구현은 Moirai 경로를 제공한다. [1,2]

[확인] Deep Factors for Forecasting(2019/ICML)은 전역 잠재 성분과 지역 성분의 결합을 다룬다. 따라서 “공통 흐름과 잔차를 나눴다”만으로는 새로운 방법의 기여가 아니다. [3]

[확인] 기존 Chronos-2 파일럿에서 R4의 PILOT MSE는 0.210964, U8은 0.230166이었다. 반면 R4의 추론시간 절감은 없었고, CAL에서는 작은 선형모델이 크게 우세했다. 이 결과는 탐색 단서이며 공식 AdaPTS 재현, 일관된 개선, 효율성 입증이 아니다. [4]

[확인] 저장소 설치 기록에는 AdaPTS·Moirai-1.1-R-small·Weather가 확보되어 있다고 기록되어 있다. 설치/import 확인과 실제 GPU 학습 성공은 구분한다. [5]

[판정] 현재 추천은 “새롭고 성공이 확정된 후보”라는 뜻이 아니라, 완전히 새로운 데이터·문제·코드를 동시에 만들지 않고 한 가지 변경의 필요성을 직접 반박할 수 있다는 선택이다. 가장 큰 위험은 기존 압축＋선형 예측 조합 이상의 가치가 남지 않는 것이다.

## 3. 첫 비교의 고정 범위

[추정·미검증] 준비된 AdaPTS/Moirai-1.1-R-small 경로와 Weather를 사용한다. 문서상의 기존 맥락 길이 512, 예측 길이 96을 첫 비교안으로 사용한다. 앞선 작은 Chronos-2 결과와 원점수를 직접 비교하지 않는다. 새로 시험하는 것은 잔차 경로 한 가지이며, 백본·분할·예측 길이·정규화를 동시에 바꾸지 않는다.

후보: 잠재 채널 4개의 학습형 압축 적응 + 과거 압축 잔차를 받는 작은 시간 예측 모듈.

비교군:
- 동일한 잠재 채널 4개의 원 압축 적응.
- 잠재 채널 8개의 원 압축 적응.
- 같은 크기의 작은 시간 모듈에 잔차가 아닌 원자료를 제공하는 우회 경로.
- 고정 PCA 압축 + 같은 잔차 모듈. PCA는 주성분분석이다.
- 작은 시간 예측 모듈만 사용하는 구성.
- 동일 백본의 일반 LoRA. LoRA는 저랭크 가중치 적응이다.

기준선에 단순 구성을 남기는 이유: 잔차 분리, 학습형 압축, 대형 모델, 그리고 효율적인 적응이 각각 필요한지를 직접 확인하기 위해서다.

모든 비교는 같은 학습 원점 목록과 검증 선택 원칙을 사용한다. 비교 가능한 공통 모듈은 같은 초기 상태를 사용하며, 서로 다른 구조에는 동일 가중치를 억지로 요구하지 않는다. 공통 손실·입력 정보·자료형·모델 선택 예산을 고정한다. 두 난수 설정을 짝지어 사용하되 두 번만으로 강한 통계적 확증을 주장하지 않는다. [6]

원점별 예측, checkpoint, 학습곡선, 학습 파라미터 수, 최대 GPU 메모리, 전체 출력 한 건의 추론시간을 저장한다. Encoder/Decoder/잔차 경로를 시간 측정에서 제외하지 않는다. 동결 백본을 통한 Encoder 역전파 비용도 포함한다.

## 4. 두 작업일의 선택 예산

[추정] 두 작업일은 성공 보장이나 실측 실행시간이 아니라 이번 가지에 배정할 작업 예산이다. 첫 실행 속도로 예산의 실현 가능성을 확인하고, 시간 부족을 이유로 다른 백본이나 과도하게 짧은 학습으로 몰래 바꾸지 않는다.

첫 작업일: 실행본에서 기준선과 후보의 실제 학습·추론을 시작한다. 설치 확인만 하고 종료하는 별도 사전점검 과제로 만들지 않는다. 기초 입력·gradient·저장 복원 검사는 실제 실행의 첫 단계로 포함한다.

둘째 작업일: 동일 조건의 두 번째 난수 설정과 저장된 예측을 이용해 방향·비용·단순 대조의 우열을 정리한다. 후보 1개와 비교군 6개의 두 설정, 최대 14개 학습 작업이 계획 상한이다. 기술 오류는 효과의 실패로 판정하지 않는다. 결과를 본 뒤 seed나 방법을 계속 추가하지 않는다.

학습곡선이 개선 중인데 예산이 끝나면 ‘현재 예산으로 판단 불가’라고 한다. 64회 등의 임의 단축 학습 결과로 후보 자체가 틀렸다고 결론 내리지 않는다.

## 5. 끝나는 방식

- 유지: 단순 대조 대비 예측과 측정 비용에서 추가 가치가 있고, 두 실행에서 그 방향이 유지된다. 다음 검증은 독립된 데이터·기간에서의 재현이며 첫 파일럿은 논문 확증이 아니다.
- 종료: 원자료 우회, 고정 PCA, 작은 모델, 잠재 차원 증가 또는 일반 LoRA가 같은 자원에서 같거나 더 좋고 후보만의 이득이 남지 않는다. 이름·설명을 바꿔 살리지 않는다.
- 보류: 추정 오차나 학습 미완료로 우열이 불명확하다. 효과 없음이나 동등성을 증명했다고 표현하지 않으며 추가 실행을 자동 승인하지 않는다.

2% 개선, 3/4 승리 등의 새로운 합격선을 임의로 만들지 않는다. 실제 값과 변동을 보고 해당 주장에 필요한 추가 가치가 있는지 판단한다. 비열등성을 주장하려면 허용할 정확도 손해를 결과를 보기 전에 별도로 합의한다.

이 주제를 선택한다고 학회 채택이나 새로운 방법의 효과를 보장하지 않는다. 주제의 질문은 지금 선택할 수 있지만, 결과와 신규성은 연구로 검증해야 한다.
