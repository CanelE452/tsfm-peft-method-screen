# C3/MAG 영향 크기 감사 — 사후 기술 분석

2026-09-18. 기존 결과를 관찰한 뒤 수행하는 진단이다. 새 학습·모델 추론·bootstrap·선택은 0회다. 결과 확인 전에 아래 계산 범위를 고정한다. 새로운 독립 실험이나 사전등록으로 부르지 않는다.

1. 기존 ALL_ORIGIN_SCORES의 C3와 MAG_ONLY를 seed×origin×channel에 정확히 대응시킨다. 3패널의 표준10조건·형태9조건을 모두 계산하고 FAULT는 기존6개 fault 조건의 동일 가중 평균으로 추가한다.
2. 오차 차이 d=nMAE(C3)−nMAE(MAG)를 계산한다. 양수는 MAG 이득이다. 평균 차이의 seed별 signed 기여와 seed·channel·index-week 하나씩을 제외한 민감도를 구한다. 제외는 진단이며 공식 평가 점수나 포함 대상을 변경하지 않는다.
3. 균형 배열 d[seed, origin, channel]의 중심화된 제곱합을 직교 주효과3개, 이원 상호작용3개, 삼원 상호작용으로 정확히 분해한다. 이것은 관찰된 국소 오차 차이의 이질성 비율이다. 평균 이득의 원인 비율, 모집단 분산 추정, 인과 중요도, 유의성 검정이 아니다. 인접 origin의 시간 의존성도 제거하지 않는다.
4. 실제 학습 기록과 checkpoint를 읽어 seed와 함께 바뀐 B0·초기 어댑터·순서, 같은 seed 안의 공통 초기값·데이터·LR·선택 step을 확인한다. 원인들 사이의 순위를 기존 기록으로 식별할 수 없으면 그대로 기록한다.
5. 합성 수학 검산, 부모 원점/seed/전체 집계 재현, 60개 조건 포함 여부, 입력 해시 보존을 검사한다. 기존 E에서 가장 좋은 조건을 새 방법으로 선택하지 않는다.
