# TRP의 선행 대비 주장 한계 — 평가 전 검토

2026-09-19. 학습 실행 중이지만 새 E 채점 전 작성. 이 문서는 비교 조건을 바꾸지 않는다.

**반응 보존 손실 자체를 새로 발명했다는 주장은 사용할 수 없다.** GAD의 식6은 교사와 학생에 원 입력·변형 입력을 넣고 두 출력 차이를 맞추는 형태다. 식7은 이를 기존 목적함수에 더한다. TRP도 이 계열에 속한다. [GAD 원문 §4.1–4.2, 식6–7](https://arxiv.org/html/2606.01651v1). 여기서는 2026 preprint로 취급하며 정식 게재를 확인했다는 뜻이 아니다.

TRP의 구체화는 관측 시계열의 suffix 수준 변화, 유한 크기의 probe, TRAIN sigma로 정규화한 L1 손실, 동결된 B0 위 작은 추가 어댑터다. 이것들은 구현 차이이며, 차이가 존재한다는 사실만으로 충분한 학술적 신규성이 생기지는 않는다. 시계열 특유의 문제에서 이 선택이 필요한지 직접 비교로 보여야 한다.

Jacobian matching·증류·입력 잡음·전이의 연결은 더 오래된 연구에도 있다. 따라서 'PEFT에서 입력 변화 반응이 중요하다'는 일반 주장도 새 원리로 제시하지 않는다. [Srinivas & Fleuret, ICML2018](https://proceedings.mlr.press/v80/srinivas18a.html).

| 주장 | 현재 판단 |
|---|---|
| 새 학습 절차를 실제 TSFM에 구현했다 | 코드·실모델 smoke로 확인 |
| 반응 차이를 맞추는 일반 수식이 새롭다 | 선행과 겹침, 주장 불가 |
| 지속 변화의 시간 구조가 필요하다 | SHUFFLE 직접 대조 결과 대기 |
| teacher 반응이 단순 규칙보다 낫다 | IDEAL 직접 대조 결과 대기 |
| 단순한 보정 억제보다 낫다 | ANCHOR 직접 대조 결과 대기 |
| 새로운 방법론 논문을 쓸 근거가 충분하다 | 아직 미확립 |

일반 손실을 새 도메인에 적용한 것이라는 반론에 답하려면, 목표 문제의 명확성·구성요소의 필요성·실질적인 정확도와 자원 절충·독립 확인이 필요하다. 현재 파일럿이 긍정적이어도 이 요건 전체가 자동 충족되지는 않는다. 반대로 불리한 seed나 source를 지워 새로운 주장을 만들지 않는다.

Time-PEFT는 주파수·채널 구조를 구현한 별도 방법이다. 우리 목적함수 연구를 그 코드의 재현이나 정식 head-to-head 비교로 쓰지 않는다. 확인한 실제 commit과 run.py hash는 [PRIOR_CODE_AUDIT.json](../../results/temporal_response_peft_20260919/PRIOR_CODE_AUDIT.json)에 있다.
