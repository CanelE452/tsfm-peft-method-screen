**새로 드러난 교란 — LEARNING_SCALE_CONFOUND**
`_compute_loss` 의 `loss.mean(-1).sum(-1).mean()` 마지막 평균 분모가 행 수다.
공변량 행은 분자에 0 을 기여하지만(마스킹 정상) 분모에는 들어간다.
```
target 행만       batch=1  per_row=[0.200691]          scalar=0.200691
target+공변량 2행  batch=3  per_row=[1.271318, 0, 0]   scalar=0.423773
target_row/scalar = 3.0000 = batch
```
INPUT arm(FI/LI)은 상태를 행으로 넣어 같은 오차에 더 작은 scalar loss 를 받고 MOD arm 은 아니다.
두 축을 "순수 위치 효과" 로 해석할 수 없다. 본실험 전에 공통 보정 계약이 필요하다.

**세 번의 실패와 원인** (`RUN_MANIFEST.json` retry_ledger)
1. `element 0 does not require grad` — backbone 전체 동결 + LoRA 미부착. 지시문 요구를 빠뜨림
2. `log_tau.grad = nan` — future_covariates NaN + 마스크 미지정
3. `log_tau.grad = nan` (다른 원인) — anomaly detection 으로 특정: `AsinhBackward0`.
   `_compute_loss` 가 NaN 이 든 future_target 을 instance_norm→arcsinh 에 통과시킨다
   (`model.py:532`, `chronos_bolt.py:120`). `future_target_mask` 명시로 해결

허용오차·assertion 은 바꾸지 않았다. 예산 forward 24/64, backward 10/24, update 0/24, 전부 CPU.
