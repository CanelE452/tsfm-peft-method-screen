# Train-only memory-efficient PEFT feasibility study

Authorized after the user asked to pursue the recommended memory-saving PEFT topic. Preserve the historical seven-candidate screen, Candidate05 recovery and Freshness v2. This study does not reopen their failed branches or their E sets.

Stage A profiles pinned Chronos-2 float32 rank8 attention LoRA at336/1024/2048/4096 context, horizon48, batch8 (two groups of4 channels). Read only the first4 source-order channels of ETTm2 and Electricity `fit.npz`; origins4352/4608 and all labels precede the existing validation boundaries. No E file is opened. Four LR1e-4 warmup updates per dataset at context1024 make LoRA-A gradients nonzero; these eight updates are diagnostic setup, not a full fit or performance evidence. Save a fixed adapter state and gradients for every profile case. No parameter updates occur in the measured passes.

Report model/optimizer memory, actual CUDA peak allocated/reserved memory, and three repeated forward/backward timings. A separate saved-tensor inventory deduplicates storage aliases and excludes parameter storage. The summed saved-activation footprint is not called the measured peak. Stage-A inventory hooks are excluded from timed passes. Respect the model's8192 context limit; assert the encoder does not silently truncate input. Single GPU lock and30-second idle wait; existing memory/time guards; no external processes terminated.

Stage B, if activations offer substantial headroom, will compare temporal compression against generic compression on the fixed warm state and train-only probes. Match retained bytes, check exact forward output and compare full-gradient and LoRA-A-gradient errors. Include exact checkpointing and activation quantization as practical controls; direct CARE-LoRA reconstruction is a useful LoRA-local control. Architecture-wide compression is a different approximation than CARE's local A-gradient approximation and must be labeled as such. Do not claim full official reproduction of methods that are only implemented as clearly scoped primitives.

Proceed to a small learning pilot only if the temporal candidate has a reproducible memory/gradient advantage across both datasets over the strongest relevant control. Otherwise report the bottleneck and STOP rather than spending another broad fit budget. The aspirational end goal is at most0.5% forecasting-loss degradation and at least30% **total peak** memory reduction; neither is a measured result or guaranteed feasibility.

Prior boundaries inspected before running: [LoRAct](https://arxiv.org/html/2509.23472v1) already compresses activations generally; [CARE-LoRA](https://arxiv.org/html/2607.11940v1) saves the natural low-rank activation plus a reconstruction matrix and approximates the A gradient while keeping B and inter-layer propagation exact; [VeLoRA](https://arxiv.org/abs/2405.17991) compresses sub-token representations. Temporal structure would need a demonstrated advantage, not merely a renamed application of these methods. Their reported results are not our results.
