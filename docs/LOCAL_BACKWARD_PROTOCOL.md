User approved implementation and zero-update profiling, then authorized learning. Learning remains conditional on the fixed feasibility gate in `configs/local_backward_feasibility.json`; no new permission is needed if the gate passes. Maximum pilot16 fits with all recipes, selection and stopping rules fixed there. If the gate fails, stop this primitive; do not claim all temporal codecs are impossible. Historical results remain immutable.

## Scope

Chronos-2 pinned base and existing warmed rank8 adapters; first4 channels of ETTm2/Electricity, fit-only origins4352/4608, contexts1024/4096, horizon48, batch8. No V/E access during diagnosis. Native LoRA multiplier2 remains outside the custom A projection. The custom operation returns exact Z=X A^T, computes grad_input=incoming@A exactly and approximates only local grad_A. Native B backward remains unchanged. Sampling sees forward activations only. Frozen base, normalization, attention and MLP backward are unchanged. REG/future last4 tokens remain exact for residual coding. Group attention tensors are transposed back to B,T,D before pairing; batch/channel boundaries never crossed.

Residual codec stores FP32 pair means and ceil(number_of_pairs/4) details sampled independently with replacement per batch series. Probabilities are90% detail norm and10% uniform; all-zero details use uniform. Backward uses inverse-probability correction; no full X reconstruction. All-details mode deterministically retains every detail, not an equal-sized with-replacement draw. QKV codecs share payloads by input storage identity and view; weak storage identities do not retain original allocations. CARE decoder is A-dependent and cannot use that sharing rule. Measure actual allocation, not cumulative encoded payload sums.

Controls: standard FP32 LoRA; exact block checkpoint; generic local FP16; CARE-style Z+ridge decoder; PRAC-style randomized principal rank8 plus independent orthogonal-complement rank8 with dimension scaling; residual; BF16 autocast standard; BF16 autocast checkpoint. PRAC basis is rebuilt each pass with all QR/projection costs included. This randomized principal primitive is not the official SVD/lazy-update implementation, and its smaller payload is not byte-matched to residual. Direct comparisons are empirical memory/time/error tradeoffs, not full-paper reproductions or a claim to beat optimized kernels. FP32 AdamW moment tensors are resident in every arm, including AMP. No optimizer step; full training-step peak remains unmeasured unless the pilot runs.

Three rotated timing repeats per arm/case; stochastic PRAC/residual use16 codec seeds total per case for variance. This gives200 measured comparison backwards plus4 exact references and12 integration parity backwards =216. Finite-sample mean error is not a proof of unbiasedness; CPU exhaustive enumeration establishes only the small synthetic estimator identity. Report individual draws, mean and RMS error, and centered variance. Initial B is the nonzero warmed B; no trivial A-gradient checks.

## Gate fixed before GPU results

For BOTH datasets at4096: at least5% actual peak reduction versus standard, at most15% time overhead, residual A-gradient RMS error no greater than generic local FP16, and no domination in both peak and time by checkpoint or AMP checkpoint. All FP32 codec forwards exact; B/input relative error<=1e-5 and all-details A error<=1e-5. This conservative gradient gate is only a spending decision, not a forecasting-quality success criterion. Previous30% whole-peak target is not retained for this smaller local-only scope. No thresholds/recipes expanded after measurement.

The conditional pilot uses two datasets × two seeds × four arms, at most16 fits,240 updates each, fixed batch and LR. Primary success requires forecasting degradation<=0.5% relative to the strongest selected control plus a practical peak/time benefit, as specified in the config. No microbatch change; record fixed-update and fixed-wall-clock trajectories. All selection sealed before reused development E; never call that an independent holdout.

Prior boundaries: [CARE-LoRA](https://arxiv.org/abs/2607.11940), [PRAC](https://arxiv.org/abs/2602.23111), [GACT](https://proceedings.mlr.press/v162/liu22v.html). Principal+random residual and local A-only approximation are not new contributions. Temporal low-variance coding without SVD is an unverified candidate. ReLU sign-mask optimization and forecast-query side adaptation are not developed in this experiment.
